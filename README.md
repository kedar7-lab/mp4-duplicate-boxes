# MP4 Duplicate Boxes Generator

Generate intentionally malformed MP4 files with duplicate `minf` (media information) and/or `mdia` (media) boxes for testing and debugging purposes.

## Overview

This project creates test MP4 files with structural violations according to the ISOBMFF (ISO Base Media File Format) specification. These files are useful for:

- Testing MP4 parser robustness
- Debugging media handling code
- Understanding ISOBMFF box structure
- Validating error handling in media applications

## What are Duplicate Boxes?

In a valid MP4 file:
- Each **track** (`trak`) contains **exactly one** `mdia` box
- Each **media box** (`mdia`) contains **exactly one** `minf` box

### Duplicate `minf` Box (Invalid)
```
trak
├── tkhd (track header)
└── mdia (media box)
    ├── mdhd (media header)
    ├── hdlr (handler reference)
    ├── minf (media information) ← First
    └── minf (media information) ← DUPLICATE ⚠️
```

### Duplicate `mdia` Box (Invalid)
```
trak
├── tkhd (track header)
├── mdia (media box) ← First
│   ├── mdhd
│   ├── hdlr
│   └── minf
└── mdia (media box) ← DUPLICATE ⚠️
    ├── mdhd
    ├── hdlr
    └── minf
```

## Installation

No external dependencies required. The script uses only Python standard library modules:
- `struct` - Binary data packing
- `os` - File operations
- `datetime` - Timestamp handling

```bash
# Clone the repository
git clone https://github.com/kedar7-lab/mp4-duplicate-boxes.git
cd mp4-duplicate-boxes

# Run the generator
python3 generate_mp4_duplicate_boxes.py
```

## Usage

### Basic Generation

```bash
python3 generate_mp4_duplicate_boxes.py
```

This creates an `output/` directory with two test files:
- `mp4_with_duplicate_minf.mp4` - MP4 with duplicate minf boxes
- `mp4_with_duplicate_mdia.mp4` - MP4 with duplicate mdia boxes

### Testing with ffprobe

Inspect the box structure:

```bash
# Show all boxes
ffprobe -show_boxes output/mp4_with_duplicate_minf.mp4

# Show verbose box information
ffprobe -show_boxes -v verbose output/mp4_with_duplicate_minf.mp4
```

### Testing with mp4dump

Use Bento4's mp4dump tool (if installed):

```bash
mp4dump --verbosity 3 output/mp4_with_duplicate_minf.mp4
```

## Script Structure

### `MP4BoxWriter` Class

Utility class providing static methods to create ISOBMFF boxes:

| Method | Description |
|--------|-------------|
| `write_box_header()` | Creates a basic box header (size + type) |
| `write_full_box_header()` | Creates a full box header (size + type + version + flags) |
| `create_ftyp_box()` | File Type Box |
| `create_mvhd_box()` | Movie Header Box |
| `create_mdhd_box()` | Media Header Box |
| `create_hdlr_box()` | Handler Reference Box |
| `create_vmhd_box()` | Video Media Header Box |
| `create_smhd_box()` | Audio Media Header Box |
| `create_dinf_box()` | Data Information Box |
| `create_stbl_box()` | Sample Table Box |
| `create_minf_box()` | Media Information Box |
| `create_mdia_box()` | Media Box |
| `create_tkhd_box()` | Track Header Box |
| `create_trak_box()` | Track Box (with optional duplicate mdia) |
| `create_moov_box()` | Movie Box |

### Generation Functions

| Function | Output | Purpose |
|----------|--------|---------|
| `generate_mp4_with_duplicate_minf()` | `mp4_with_duplicate_minf.mp4` | Two minf boxes in one mdia |
| `generate_mp4_with_duplicate_mdia()` | `mp4_with_duplicate_mdia.mp4` | Two mdia boxes in one trak |

## MP4 Box Hierarchy

Complete box structure generated by this tool:

```
ftyp (File Type Box)
├── Brand: isom
├── Minor Version: 512
└── Compatible Brands: isom, iso2, mp41

moov (Movie Box)
├── mvhd (Movie Header)
│   ├── Creation Time: 3600
│   ├── Modification Time: 3600
│   ├── Timescale: 1000
│   └── Duration: 3000
└── trak (Track Box)
    ├── tkhd (Track Header)
    │   ├── Track ID: 1
    │   ├── Duration: 3000
    │   ├── Width: 320 (16.16 fixed point)
    │   └── Height: 240 (16.16 fixed point)
    └── mdia (Media Box) [potentially duplicated]
        ├── mdhd (Media Header)
        │   ├── Timescale: 1000
        │   └── Duration: 3000
        ├── hdlr (Handler Reference)
        │   └── Handler Type: vide (video)
        └── minf (Media Information) [potentially duplicated]
            ├── vmhd/smhd (Video/Audio Media Header)
            ├── dinf (Data Information)
            │   └── dref (Data Reference)
            │       └── url (Self-referencing)
            └── stbl (Sample Table)
                ├── stsd (Sample Description)
                ├── stts (Time to Sample)
                ├── stsc (Sample to Chunk)
                ├── stsz (Sample Size)
                └── stco (Chunk Offset)
```
